# Design System: Serene Precision (DayPivot)

## Brand Identity
DayPivot is a decision-making assistant designed to provide clarity and focus. The visual language is calm, professional, and gender-neutral, utilizing an airy aesthetic to reduce cognitive load during the decision process.

## Color Palette
- Primary Action: #334155
- Accent: #14B8A6
- Background Gradient: #E0F2FE to #BAE6FD
- Surface Cards: #FFFFFF
- Success: #22C55E
- Critical/Emergency: #14B8A6
- Text: #0F172A

## Typography
- Headings: Poppins Bold
- Body & Functional UI: Inter Regular/Medium

## Components & Layout
- Corner Radius: 16px
- Shadows: Soft subtle shadows
- Spacing: Compact vertical rhythm optimized for 390x881 mobile viewport

## Shared UI Patterns
- Primary Button: Filled #334155 with white text
- Secondary/Ghost Buttons: Outlined or subtle backgrounds
- Input Fields: Light borders with clear focus states
- Progress Indicators: Clean progress bars
- Result Gauges: Large circular elements for numerical confidence scores
